# Handy Sam - Handyman Services

Welcome to the Handy Sam project! This is a Next.js web application designed to showcase the services of Handy Sam, your reliable handyman.

## Features

- **Hero Section**: A prominent welcome message and key services offered.
- **Services**: Detailed descriptions of the handyman services available.
- **Gallery**: A collection of images showcasing Handy Sam's work, integrated with Google Photos.
- **About**: Information about Handy Sam, including background and experience.
- **Contact**: A contact form for potential clients to reach out.

## Getting Started

To get started with the Handy Sam project, follow these steps:

1. **Clone the repository**:
   ```
   git clone https://github.com/yourusername/handy-sam.git
   ```

2. **Navigate to the project directory**:
   ```
   cd handy-sam
   ```

3. **Install dependencies**:
   ```
   npm install
   ```

4. **Run the development server**:
   ```
   npm run dev
   ```

5. **Open your browser** and go to `http://localhost:3000` to see the application in action.

## Project Structure

- `src/app`: Contains the main application files including components and styles.
- `src/lib`: Manages data fetching and static data.
- `src/types`: Defines TypeScript interfaces and types.
- `public/images`: Directory for images, including a `.gitkeep` file to track it in Git.
